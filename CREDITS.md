# Credits and sprite sources

Naruto characters and setting: Masashi Kishimoto, Shueisha, and Studio Pierrot.

MUGEN character packs in the workshop include work credited to YOUKAI, CobraG6, and Real Mugen Youtube. The baked release also contains game-generated stand-ins and recoloured variants; those entries are not claims of separate original character packs.

Source collections:

- https://charmanmugen.blogspot.com/2024/06/hanyous-youkais-mugen-creations.html
- https://www.mugenation.it/2022/11/03/naruto-mugen-characters-download-list/
- https://mugenfreeforall.com/topic/47611-matatabi-naruto/

The original MUGEN archives and their included credit files are retained in the local sprite workshop. This web release includes only the baked assets needed by the game.
