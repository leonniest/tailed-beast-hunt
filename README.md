# Tailed Beast Hunt

Play: https://leonniest.github.io/tailed-beast-hunt/

A Naruto fan roguelike: draft a squad of three and climb three maps to seal the Three-, Six-, and Nine-Tails.

Mouse: click to choose, right-click to go back, wheel to scroll. Keyboard: arrows move, Z confirm, X back, C menu, V skip, Q/E page; hold E for fast battles. Gamepads are supported. Saves stay in your browser.

This repository contains the static web release, including compiled game rules and baked sprite atlases. GitHub Pages serves the main branch at its root.

To update, copy a fresh static release into this repository, retain .nojekyll, commit, and push main.

Naruto belongs to Masashi Kishimoto, Shueisha, and Studio Pierrot. This is an unofficial fan project. Sprite credits and sources are listed in CREDITS.md.
